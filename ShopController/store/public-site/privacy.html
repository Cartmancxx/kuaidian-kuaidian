快店快点

隐私政策

开发者：程大意 · 生效日期：2026 年 10 月 28 日 · 适用版本：1.0

快店快点用于管理店铺后台入口，并通过用户安装的本地助手，在指定 Google Chrome 资料中打开网址。本政策覆盖扩展及配套本地助手。

1. 处理哪些数据

  • 你主动填写的店铺名称、平台、账号昵称、后台入口网址、备注、Chrome 资料绑定和最近打开时间。
  • 本机 Chrome 程序路径、资料根目录，以及从 Chrome 的 Local State 中提取的资料目录标识和显示名称。
  • 扩展在当前浏览器会话中保存自己创建的小窗 ID，用于找回同一小窗。连接诊断使用助手版本、系统类型及功能状态。
  • Windows 置顶功能使用 Chrome 传入的本次调用窗口句柄，并检查所属进程；不枚举其他应用的内容。Mac 版不执行置顶。

2. 数据用途和存储

上述数据仅用于显示店铺、检查绑定冲突、提出资料配对方案、打开指定入口和连接诊断。店铺配置及上一版备份保存在本机用户目录；不包含工具读取的 Cookie 或 Chrome 密码数据。本产品不提供云端账号、遥测、广告、跟踪或配置同步服务，不将上述配置主动上传给开发者或出售给其他方。

3. 不读取哪些内容

扩展不请求全站页面读取、浏览历史、Cookie 或密码读取权限；本地助手不读取 Chrome 的 Cookies、Login Data 或历史数据库。不要求你提供平台密码、验证码或登录凭证。请勿在昵称、备注或后台网址中填写这些秘密信息。

4. 与网站、浏览器和客服的交互

点击店铺后，Chrome 会按自身设置访问你填写的网址；平台网站、Chrome 同步及其他已安装扩展的行为适用它们各自的政策。本工具不改变这些设置。产品官网使用 GitHub Pages，源码与下载通过 GitHub Releases 提供。访问这些服务时，GitHub 可能按其隐私政策处理 IP、设备和请求日志；这不属于扩展或助手上传店铺配置。本站不加入访问统计或跟踪脚本。你主动访问商店或发送支持邮件时，相应服务会处理该请求；我们只使用你主动提供的支持信息处理问题。请勿通过邮件发送 Cookie、密码或包含敏感订单数据的日志。

5. 权限说明

  • nativeMessaging：与已安装的本地助手通信，选择 Chrome 资料打开入口，并在 Windows 上操作调用小窗的置顶状态。
  • storage：仅在浏览器会话内保存本扩展的小窗 ID；不使用 Chrome 云同步存储店铺配置。

6. 删除、卸载与保留

可在管理页删除店铺入口；此前配置可能仍保留在本机上一版备份中。卸载助手会移除本产品的通信登记，并保留助手程序供核对或恢复（Mac 归档保留）；默认保留店铺配置，避免误删。若要彻底清除本产品配置，请删除 Windows 的 %LOCALAPPDATA%\ShopController\config.json 及其 .bak，或 Mac 的 ~/Library/Application Support/ShopController/config.json 及其 .bak。本产品不删除 Chrome 资料或网站登录状态。

7. 更新和联系

如未来新增数据处理用途，将更新政策并在需要时取得同意。隐私、删除与支持问题请联系开发者程大意：cartmancxx@gmail.com。
