# 权限与隐私实践填写依据

本文件是与代码对应的事实清单；提交时以商店后台当日字段定义为准。不要简单把“没有上传”写成“没有处理任何用户数据”。

## 单一用途
通过紧凑的店铺入口小窗和本地助手，在用户指定的 Chrome 个人资料中打开店铺后台网址。

## nativeMessaging 理由
扩展通过 Chrome 官方 Native Messaging 与用户安装的本地助手通信。助手读取本机资料列表、保存店铺入口与资料绑定、以指定 Chrome 资料启动后台网址；Windows 还按 Chrome 传入的调用窗口实施小窗置顶。助手只允许安装时指定的扩展来源，不接受任意执行命令，不读取 Cookie 或密码。普通网页没有调用入口。

## storage 理由
仅使用 chrome.storage.session 保存本扩展小窗的 window ID，避免重复打开。浏览器关闭后会话存储清除。不使用 sync 存储店铺配置。

## 远程代码
选择“不使用远程代码”：扩展 JS/CSS 均随 ZIP 提供，无远程脚本、eval、远程 WASM 或远程更新器。本地助手单独由用户安装；nativeMessaging 调用预置操作，不下载或执行服务器返回的代码。首次连接只读取本地打包的 release-info.json。

## 数据事实表
| 数据 | 来源 / 用途 | 保存和去向 |
| --- | --- | --- |
| 店铺名、平台、账号昵称、入口网址、备注 | 用户填写，显示/搜索/路由 | 本地配置及上一版备份 |
| Chrome 资料目录和显示名 | Local State 资料信息，建立绑定 | 本地内存/绑定标识 |
| 最近打开时间 | 用户点击入口，管理界面显示 | 本地配置 |
| Chrome 路径、资料根目录 | 自动检测或用户选择 | 本地配置 |
| 小窗 ID | Chrome，找回自身小窗 | storage.session |
| 版本、系统与功能状态 | 本地助手，连接诊断 | 展示，不遥测 |
| Windows 调用窗口标识 | Chrome 启动参数，验证并设置小窗 | 临时使用，不遥测 |

账号昵称或资料显示名可能包含个人身份信息；备注和入口地址可能含商业信息。产品提示勿填密码或令牌，但自由文本的真实内容由用户决定。若后台字段按“访问/处理”定义数据，需据此披露，而不只按服务器收集判断。没有读取浏览历史数据库或全站页面内容；最近打开记录是产品自身的使用数据。不要将这两者混为一谈。

## 用途声明
- 不出售用户数据。
- 不用于与本产品单一用途无关的广告、画像、信用评估或借贷目的。
- 不主动向开发者或第三方发送配置；网站访问仍由 Chrome 正常发起。
- 用户主动联系支持的邮件由邮箱服务处理；不应发送凭据或订单信息。
- 删除/卸载保留行为与公开隐私政策一致。
