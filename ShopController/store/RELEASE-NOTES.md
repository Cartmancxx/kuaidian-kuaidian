# 1.0.0 公开测试版发布说明

产品名：快店快点。开发者：程大意。公开支持邮箱：cartmancxx@gmail.com。

- 紧凑店铺小窗、平台分组和搜索；独立管理页。
- 现有 Chrome 资料绑定与配对预览；淘宝/天猫按同一体系检查冲突。
- Windows 调用小窗置顶与状态回读；Mac 普通独立小窗。
- Mac Chrome 资料路径支持；Windows/macOS 原生助手架构包。
- 连接页、助手版本/协议握手、缺失助手引导、身份精确绑定。
- MV3 最小权限；正式包无演示数据、无远程代码；本地配置和备份。
- 运行时升级至 .NET 10，附运行时许可通知。
- Windows 安装入口直接调用本地程序，不要求修改 PowerShell 执行策略。
