快店快点连接助手

安装一次，按店铺打开后台

快店快点包含 Chrome 扩展和配套本地助手。扩展只管理入口；账号登录和网页插件仍由原生 Chrome 管理。

安装与连接

  1. 从GitHub 公测 Release下载名称含 extension-unpacked 的扩展 ZIP，解压到长期保留的目录。打开 chrome://extensions，启用开发者模式，点击“加载已解压的扩展程序”，选择包含 manifest.json 的目录，再固定工具栏图标。
  2. 打开“连接助手”页，获取与你系统匹配的本地助手。
  3. Windows：完整解压后运行 Install.cmd。Mac：选择 Apple 芯片或 Intel 版，解压后按说明运行 Install.command。
  4. 安装器如询问扩展 ID，从“连接助手”页复制当前实际 ID。
  5. 返回连接页检查版本，再进入店铺管理。

本地助手按用户安装，自动创建本产品目录并登记通信。当前 GitHub 公测助手未签名／未公证，Mac 未完成真实运行验收；不是 Chrome 商店版。遇到系统拦截请核对来源并遵循设备策略，不关闭 Gatekeeper 或其他系统防护。未来商店版将另行提供对应安装说明。

系统与小窗

目标环境为受支持版本的 Windows 11 x64，以及 macOS 15 或之后受 .NET 10 支持的版本（Apple Silicon / Intel）。扩展需要 Chrome 116 或更新版本，建议使用最新稳定版。Windows 小窗默认申请置顶，也可临时取消。Mac 使用普通独立小窗，不置顶。此功能不是多资料合并成一个 Chrome 窗口。

添加店铺

  1. 填写店名、平台、账号昵称及后台网址；不要填写密码或临时登录链接。
  2. 选择一份已存在的 Chrome 资料。资料不足时先在 Chrome 中手动创建，再刷新。
  3. 点击店名打开后台，在页面里核对实际店铺和账号。

三个京东账号加两个淘宝账号理论上可使用三份资料。淘宝和天猫按同一登录体系处理。同一账号使用同一昵称，不同账号使用不同昵称；未登记的账号不参与冲突检查。

精简配对

先勾选允许用于电商的资料，预览后确认。日常主资料可以不选。配对只修改入口绑定，不复制 Cookie、不改变登录账号、不删除 Chrome 资料；换绑后可能需要重新登录。

GPT 与其他插件

后台仍在原生 Chrome 中运行。插件的安装、启用和连接通常按资料分别管理，请在各资料中分别检查；本工具不修改 GPT 权限或浏览器调试配置；GPT／Codex 跨资料控制尚未实测，不承诺兼容性。

更新、卸载与数据

GitHub 扩展需解压新版到原目录并在 chrome://extensions 刷新，保留 manifest.key；不从商店自动更新。本地助手需从新下载并完整解压的匹配包重新运行安装器。协议不匹配会提示更新。助手卸载入口移除匹配通信登记，默认保留配置；Windows 保留程序，Mac 归档程序。Chrome Cookie、密码和资料不受影响。完整数据说明见隐私政策。

常见问题

  • 本地助手未连接：检查安装包来源、助手版本、扩展 ID 是否一致，再点重新检查。
  • 找不到资料：先打开一次 Chrome 资料，再刷新；设置里填写包含 Local State 的资料根目录。
  • Mac 自定义 Chrome 路径：填写应用内 Contents/MacOS/Google Chrome 的完整路径，不是 .app 文件夹。
  • 重复点击出现新标签：当前版本不复用已有业务标签，也不自动整理标签组。
  • 打开请求成功不代表已经登录；请检查实际页面。
