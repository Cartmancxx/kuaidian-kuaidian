第一次安装，三步开始

  1. 从 Chrome 商店安装。点击“添加至 Chrome”，再把快店快点固定到工具栏，不需要打开开发者模式。
  2. 安装配套本地助手。从上方下载匹配系统的包并完整解压。Windows 运行 Install.cmd；Mac 运行 Install.command。已有旧公测版时，请按下方迁移步骤显式换绑。出现系统拦截时按设备策略处理，勿关闭防护。
  3. 连接，添加店铺。点扩展图标 → 连接助手 → 重试，显示已连接后添加店铺与资料绑定。先用 https://example.com/ 测试两份资料，再配置真实后台并核对账号。

  1. 关闭小窗/管理页并备份 config.json 与存在的 .bak，在 chrome://extensions 中停用旧已解压扩展。
  2. 从商店安装快店快点，完整解压 v1.0.0-store.1 助手。在解压目录显式运行 Windows Install.cmd --replace-identity（PowerShell：.\Install.cmd --replace-identity）或 Mac ./Install.command --replace-identity。普通重装不会覆盖旧身份。
  3. 重新检查连接与店铺绑定；配置保留，不搬运 Cookie、不改写 Chrome 资料。避免同时启用两个同名入口。

完整迁移、备份与故障说明 →

资料少一点

3 个京东账号 + 2 个淘宝账号，可规划为 3 份资料。不同体系可复用，同体系不同账号分开；淘宝与天猫按同一体系处理。

边界说清楚

这是入口控制器，不会把多个资料合成一个窗口，不自动整理旧标签，不判断登录店铺。点击后仍需在真实后台核对账号。

数据留本机

保存店名、昵称、地址和绑定；不读取 Cookie、密码或历史数据库。无产品自建云同步、广告或遥测。

插件继续使用

不换浏览器、不开放调试端口。其他插件仍需按资料分别安装和连接，GPT／Codex 跨资料控制尚未做兼容性实测。
