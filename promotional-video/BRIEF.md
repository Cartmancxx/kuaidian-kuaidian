# 快店快点 · Chrome 商店上线宣传片

- 模式：用户于 2026-11-03 选择 video-shotcraft 自主创作。使用该工作流指定的 Remotion 实现；不改造成 HyperFrames。
- 输出：约 32 秒，1920×1080，30 fps，中文，无配音，带原创 BGM / 无 BGM 保留 SFX 两版，封面。
- 受众：在京东、淘宝／天猫、PDD 多个后台之间切换的商家和运营。
- 核心收益：店铺一眼找到，后台一点打开。日常是紧凑小窗，配置才进管理页；保留 Chrome 的原生资料与登录状态。
- 必须展示：实际小窗、搜索、店铺与资料绑定、不同登录体系复用资料示意、扩展 + 本地助手、商店上线 / MIT 开源。
- 禁止宣称：自动登录永不过期、GPT 兼容已经实测、同窗多 Cookie、自动归组旧标签、Mac 置顶、助手已签名公证、Chrome 审查等于本地助手认可。
- 数据：仅使用仓库公开 preview/demo.js 的虚构店铺；不访问用户 Chrome 资料、不展示真实商家后台、客户、订单或用户个人信息。演示预览用真实生产 HTML/CSS/JS，接口由独立 preview adapter 替换。
- 商店：ckeiapojbffhmmedjajdbnpfongmfjmm；主线程已核实页面标题、开发者和版本。
- 配乐：原创程序化 120 BPM 电子底，确定性种子，无第三方采样；声音设计在画面时间线确定后制作。

## 需求到执行决策
| 需求 | 执行 |
|---|---|
| 紧凑而非臃肿管理后台 | 小窗作为单一开场主角，管理页只用于解释绑定 |
| 电商运营看得懂 | 中文短句 + 清楚平台名，不做技术术语堆叠 |
| 真实产品 | 所有实际 UI 用本地预览截图，采集 2x 整页、4x 小窗、元素切片、layout.json |
| 不夸大登录 | 只呈现入口和资料路由示意，不展示伪造的登录成功 |
| 分享推广 | 1080p 横版，字幕 ≥60px、辅助 ≥36px，终屏商店搜索词 |
| 开源可复用 | 自制音频与代码，第三方动效组件保留 Apache-2.0 许可 |

视觉、分镜及独立终检基准见 DESIGN.md。
