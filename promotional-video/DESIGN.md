# 设计与分镜 · 自主定案

## 视觉方向
候选 A「轻巧有序」：暖白空间、墨绿标题、真实小窗独占主角；候选 B「夜间工作台」：深绿沉浸、聚光与 UI 特写；候选 C「多平台拼贴」：密集卡片枚举。选择 A 为主、B 仅在资料示意镜头做反差；开场用墨绿阴影收束聚光，收尾保持已定案 styleframe 的暖白舞台。不选 C，避免再次把小工具做成拥挤大后台。

Tokens 从产品 compact.css / style.css 提取：字体 Segoe UI / Microsoft YaHei / sans-serif；主色 #235c50、底 #f5f7f6、正文 #24322e、辅助 #66746e、分割 #dfe6e2。标题 82–112px，叙事 60–68px，辅助 36–40px；8px 基准栅格，屏幕安全边距 96px；产品圆角 7–13px，经镜头自然缩放。深绿背景为主色低亮度扩展 #163d34。无琥珀纸张、无霓虹、无手持抖动、无逐卡闪光。

动效：亲和 / 专业中间值，主入场 26f，bezier(.25,.46,.45,.94)，非物件入场不弹。真实物件落位沿卡片采用 y1>1 过冲，悬停完整动作弧 ≥3s。信息落定 hold≥30f，群体动画完成 hold≥15f。画面锁定后用 120 BPM = 15f/拍，所有分段边界均整拍。

## 独立审查后的实际修复

保持原分镜和全部 SFX 帧号。开场补足 local f32/36/41 的 6% 锁光脉冲、f22/32/48 的 0.16/0.34/0.42 压暗、与升降联动的空槽描边及 f126/130/134 落地脉冲；左侧叙述区加暖白 scrim 保证对比。收尾补足 f2–14 光带、8% 滞后 ghost、f42/50/58 的 0/0.5/0.25 舞台光、f58–66 延长线和 f66–72 消退。真实绑定卡片推近至 2.4 倍，使用重新采集的 4x 元素纹理，并以 44px 屏幕外解说读出「京东POP → 电商资料 2」，不修改业务 UI 内容。

验收：每镜至少2静帧；f75/145/210/300/360/450/540/630/700/750/840/930。成片截帧、480px缩图、技术音视频检查；独立终检由未参与制作的 Agent 执行。
